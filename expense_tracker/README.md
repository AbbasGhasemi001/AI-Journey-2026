# Expense Tracker

A command-line application built with Python that tracks income and expenses. Users can add, view, edit, delete, and analyze transactions, organize them by category, and save the data in a JSON file.


## Features

- Add income and expense transactions
- View all saved transactions
- Edit existing transactions
- Delete unwanted transactions
- Analyze income, expenses, and balance
- Save and load data in JSON format


## Project Structure

```text
expense_tracker/
├── main.py           # Runs the command-line menu
├── tracker.py        # Contains the core logic for managing and storing transactions
├── transaction.py    # Defines the Transaction class and handles dictionary conversion
└── README.md         # Contains the project documentation
```

